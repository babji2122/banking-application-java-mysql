# Banking Application

Console-based banking application using Java, JDBC and MySQL.

## Features
- Account creation
- Login with account number and PIN
- Balance enquiry
- Deposit
- Withdrawal
- Transaction history

## Technologies
Java | JDBC | MySQL | OOP | SQL

## Setup
1. Run `database/banking.sql` in MySQL.
2. Open `src/DatabaseConnection.java`.
3. Replace `your_password` with your local MySQL password.
4. Add MySQL Connector/J to the project.
5. Run `Main.java`.
